⚠️ New Semester Reset - Complete System Wipe
This action will PERMANENTLY DELETE ALL DATA and reset the system for a new semester. This CANNOT be undone!
🗑️ What will be deleted:
  • ALL student applications (pending, approved, rejected)
  • ALL student records from the system
  • ALL room assignments (occupancy reset to 0)
🔄 What will be reset:
  • ALL hostels - available beds reset to total capacity
  • ALL floors - available beds reset to total capacity
  • ALL rooms - occupancy count reset to 0
ℹ️ Note: Hostel, floor, and room structures will be preserved. Only the data and occupancy will be cleared.
